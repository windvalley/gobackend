# 工程环境复盘

用户要求或同类执行问题反复出现时使用；通用约束见 [core](core.md)。未要求中途复盘时先完成当前交付。

- 依据实际会话、命令和 diff 证据定位卡点；缺少记录就说明限制，不估造耗时或收益。
- 机械可判定的问题优先修复已有检查或工具；判断性问题补最小规则，重复内容合并，失效内容删除。
- 每项建议说明证据、修改位置和验证方式。复盘不自动授权修改全局指令、记忆或外部系统。
- 验证改进时区分文档检查、工具结果与真实行为；没有行为证据不宣称成功率提高。
- 修改 `.harness/` 下的规则与配置后运行 `harness golden` 重放黄金任务，确认原有判定没有退化。
